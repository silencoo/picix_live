# 双倍轻量包法自动化助手

## 策略说明

**双倍轻量包法**是最佳利润策略：

- **支出**: 每月购买2次「资源轻量包」（450分 × 2 = 900分）
- **获得**: 60次解锁机会
- **执行**:
  - 每日解锁1个视频（消耗30次，满足每日任务）
  - 确保其中至少20个来自片单（满足片单任务）
  - 剩余20次在月内任意时间使用，凑够50个总数

- **收入**:
  - 每日任务：15 × 30 = 450分
  - 月常任务（50个）：640分
  - 片单任务（20个）：100分
  - **总收入**: 1190分

- **净收益**: 1190 - 900 = **+290分/月**

## 使用方法

### 1. 配置授权Token

推荐在 Telegram Bot 中发送 `/reauth` 完成认证，新 authorization 会自动
保存到 `unlock_data/authorization.json`。

也可以临时通过 `.env` 配置：

```dotenv
PICIX_AUTHORIZATION=你的authorization
```

不要把 authorization 写进 Python 源码。

### 2. 查看当前状态

```bash
uv run --locked --env-file .env python auto_unlock_helper.py status
```

这会显示：
- 当前任务进度（每日、每月、片单任务）
- 本月解锁统计
- 今日解锁记录

### 3. 执行每日解锁

```bash
uv run --locked --env-file .env python auto_unlock_helper.py unlock
```

脚本会自动：
1. 检查每日任务是否已完成
2. 优先从片单中选择未解锁的电影（确保满足片单任务）
3. 如果片单任务已完成，从推荐列表选择
4. 执行解锁并记录
5. 显示更新后的任务进度

## 功能特点

1. **智能选择**: 优先从片单选择，确保满足片单任务要求
2. **避免重复**: 自动记录已解锁的电影，不会重复解锁
3. **进度跟踪**: 实时显示任务进度和统计信息
4. **数据持久化**: 所有解锁记录保存在 `unlock_data/` 目录

## 数据文件

- `unlock_data/unlock_log.json`: 解锁记录
- `unlock_data/status.json`: 状态缓存（如果使用）

## 建议使用方式

1. **设置定时任务**: 每天自动执行一次解锁
   - Windows: 使用任务计划程序
   - Linux/Mac: 使用 crontab

2. **手动执行**: 每天手动运行一次 `unlock` 命令

3. **监控状态**: 定期运行 `status` 命令查看进度

## 注意事项

1. 确保每月购买2次资源轻量包（手动操作）
2. 脚本会自动优先满足片单任务要求
3. 如果某天忘记执行，可以在后续日期补上（只要月内达到50个即可）
4. 建议在每天固定时间执行（如晚上）
